# CRS-R Measuring Change Toolkit - Team Review Prototype

This repository contains the current team-review prototype of the clinician-facing CRS-R measuring-change toolkit.

## Educational package
- Learn page includes a visible placeholder for the brief educational video.
- A printable one-page Quick Reference Guide is linked from Learn, Interpret Change, and Resources.
- Expandable Learn topics provide optional just-in-time education.

## Interpretation
- Shows raw and transformed CRS-R scores.
- Offers MDC90, MDC95, and cMDC95 views.
- Each view includes a result and draft clinician-facing interpretation statement.

## Before participant deployment
- Add/finalize the educational video.
- Validate all cMDC values/classifications against the authoritative published lookup table.
- Confirm final diagnostic-state and interpretation wording with the study team.
- Finalize resource links/citations and required acknowledgement language.

Research prototype for team review; not a finalized clinical calculator.
